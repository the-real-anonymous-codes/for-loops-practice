# For Loops Practice

This project contains beginner-friendly Python programs for practicing `for` loops in Python.

Each file is a small exercise focused on iteration, patterns, number sequences, strings, and problem-solving using loops.

## Requirements
- Python 3 installed on your system

## How to Run
Open a terminal in this project folder and run any program with:

```bash
python filename.py
```

Example:

```bash
python multiplication_table.py
```

If your system uses `python3`, run:

```bash
python3 multiplication_table.py
```

## Project Goal

The goal of this project is to improve Python basics by practicing:

- `for` loops
- `range()`
- Nested loops
- Pattern printing
- List iteration
- String iteration
- Mathematical problems
- Beginner problem solving
